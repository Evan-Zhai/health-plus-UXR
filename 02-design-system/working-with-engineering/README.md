# 和开发怎么同步

## 现状

设计系统主要通过 **Figma 文件和链接** 交给开发：组件库、页面 Frame、Prototype、偶尔的标注。工程师以 Figma 为「长什么样」的来源。

这套做法的优点是快、所见即所得。缺点是：Figma 里没有写下来的规则（语气、断点、网页怎么收成移动端）会在口头里消失，组件缺口也不好排期。

## 以后两边怎么分工（先执行这个）

| 内容 | 仍以 Figma 为准 | 必须在本仓库留一份 |
| --- | --- | --- |
| 组件外观、变体、间距视觉 | 是 | 组件页只写链接 + 使用规则 |
| 库发布了哪个版本 | Figma 库名 / 版本 | 本目录 [`figma-links.md`](figma-links.md) 改一行 |
| 语气、禁用词 | — | `content-and-voice/` |
| 断点、列数、怎样从网页收到手机 | 可以画批注 | `layout-and-responsive/` 写成规则 |
| 「这个组件还不能用」 | 口头或 Slack 容易丢 | `gaps-and-backlog/` |

给开发发需求时：Figma 链接 + 本仓库对应规则页链接，两样一起贴。
