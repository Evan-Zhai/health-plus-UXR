## 建议以后写进去的章节（文件夹先占住）

2. **宽度对照表**：网页 Frame 对应哪个移动 Frame；中间宽度是否要画。
3. **结构怎么收**：多栏 → 单栏的顺序（左栏先还是主列先）。
4. **导航怎么换**：顶栏、侧栏、底 Tab 的对应关系。
5. **必须保留 vs 可后置**：哪些模块到手机上改成二级页。
6. **触控**：主按钮高度、不能靠悬停才出现的操作。
7. **Figma 操作顺序**（待你补）：例如「复制 Web 页 → 改 Frame 宽 → 按本表收栏 → 换导航组件」。
8. **和开发怎么说**：只标「两套视觉」还是「一套响应式」；现在沟通渠道仍是 Figma 链接。
