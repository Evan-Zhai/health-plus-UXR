# 04 · 设计交付

设计意图要离开 Figma、进入开发和 QA 时，在这里打包。

好的交付不是「所有标注截图」，而是：**范围、状态、空与错、破例、验收标准**。

## 标准结构

```text
projects/YYYY-MM-short-name/
  README.md
  00-handoff/      给工程和产品的说明书 + 清单
  01-specs/        按界面写状态和规则
  02-assets/       切图清单（文件仍建议放在共享盘）
  03-qa/           对照设计走查
  04-release/      上线说明、已知问题
```
