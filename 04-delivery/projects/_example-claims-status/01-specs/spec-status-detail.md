# 说明 · 进度详情（示例）

对应界面：S02 / S03 / S04 / S05

## 数据（字段级，虚构）

| 字段 | 含义 | 展示 |
| --- | --- | --- |
| `stageCode` | 运营阶段代码 | 不直接展示 |
| `stageLabelEn` / `Fr` | 官方阶段名 | 时间线标题 |
| `plainLanguage` | 人话当前句 | 页头 |
| `needsMemberAction` | 是否待办 | 为真则显示行动条 |
| `missingItems[]` | 缺件清单 | 仅待办时 |
| `history[]` | 历史节点 | 时间线 |

## 显示规则

- `needsMemberAction === true`：行动条第一，时间线第二
- 接口失败：S05，禁止回落到空态
- 无历史且无当前理赔：S04

## 点击

- 「上传缺失材料」→ 现有上传路由（本项目不重做）
- 「返回」→ 理赔记录

## 截断

- 当前句最多三行，超出用完整句子在详情展开（不要用 `...` 吃掉动词）
- 法语阶段名允许折行，按钮跟着变高
