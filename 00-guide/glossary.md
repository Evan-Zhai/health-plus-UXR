# 词汇表

| 词 | 意思 |
| --- | --- |
| 业务板块 | 仓库最上面的三大类：Plus 产品、设计系统、跨产品通用 |
| 功能模块 | Plus 里的产品线切片：core / pharmacy / telemed / counselling |
| 页面 / 功能 | 模块下的稳定对象，例如 personalization、claim；长期存在 |
| 项目 | 某一页面上的一轮迭代，有起止；同一页面会有多个 |
| Design scope | 本轮做谁、解决什么、不做什么 |
| Competitor research | 竞品或类比研究（学流程，不抄界面） |
| Data analysis | 用已有数据回答设计问题（仓库里只放结论） |
| User research | 访谈、观察、日记等直接接触用户的研究 |
| Prototypes and designs | 信息架构、流程、线框、原型、视觉稿 |
| User testing | 让用户或代表用户的人走任务，检验方案 |
| Design system | 跨项目共用的原则、组件、布局和语气；当前主要存在 Figma |
| Adaptive / responsive | 界面如何随屏幕和上下文改变，而不是各画一套互不相干的稿 |
| Token | 颜色、间距等的稳定名字，方便和开发对齐 |
| WCAG | 网页无障碍标准；对外产品默认 2.2 AA |
| PHI / PII | 个人健康 / 身份信息；本仓库禁止真实值 |
