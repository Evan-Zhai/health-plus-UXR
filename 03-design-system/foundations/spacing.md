# 间距

用 4 的倍数，避免页面上出现 13px、15px 这种说不清的空隙。

| Token 草案 | 值 | 典型用途 |
| --- | --- | --- |
| `space.4` | 4 | 图标与文字 |
| `space.8` | 8 | 标签内边距 |
| `space.12` | 12 | 紧凑列表 |
| `space.16` | 16 | 默认内边距 |
| `space.24` | 24 | 区块之间 |
| `space.32` | 32 | 页面左右边（移动） |
| `space.48` | 48 | 大区块分隔 |

## 规则

- 同一列表里行距保持一致。
- 「你要做的事」和「时间线」之间用 `space.24` 或以上，让行动区先被看见。
