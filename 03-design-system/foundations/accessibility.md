# 无障碍（设计侧最低要求）

对外会员产品按 **WCAG 2.2 AA** 自检。这不是工程单方面的事：对比度、焦点态、错误提示在设计稿里就要画出来。

## 设计稿必须包含的状态

- 默认 / 悬停 / 按下 / 焦点 / 禁用
- 错误 + 错误如何与字段关联（不要只靠红框）
- 空、加载、无权限

## 检查清单（每个主界面）

- [ ] 颜色不是唯一通道
- [ ] 正文对比度达标（官方色到位后实测）
- [ ] 触控目标建议 ≥ 24×24 CSS px，重要行动更大
- [ ] 阅读顺序从上到下、从左到右说得通
- [ ] 动效不是理解内容的唯一方式
- [ ] 英法长词不会把按钮截断到看不懂

## 做不到时

写进项目交付的 QA 清单，标「已知风险」，不要假装通过。
