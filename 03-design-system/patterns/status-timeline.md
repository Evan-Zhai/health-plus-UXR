# 模式 · 状态时间线

- 状态：草案
- 验证项目：`_example-claims-status`
- 相关组件：Inline alert、文本、图标、Button

## 解决什么问题

把「现在到哪、下一步轮到谁」讲清楚，尤其适合理赔、申请、审核这类等待型任务。

## 结构（从上到下）

1. 当前句（人话，区块标题级）
2. 若用户有待办：行动条（图标 + 文字 + 主按钮）
3. 时间线：每步 = 官方阶段名 + 一句解释 + 日期（如有）
4. 帮助：什么时候该联系人

## 规则

- 当前步同时有文字标签和节点样式，不单靠颜色
- 待办永远在时间线上面
- 阶段名来自运营主数据；人话解释可以由设计写，但要业务签字
- 失败态不能画成「没有记录」

## 不要

- 地图或货车动画
- 显示内部处理人或队列名
- 用闪烁表示「正在处理」
