## 用来干什么

触发一个明确行动：上传、查看详情、重试。

## 不要用在

- 导航去一个新的信息架构节点（用链接或导航组件）
- 一屏里堆三个 Primary

## 变体

| 变体 | 何时用 |
| --- | --- |
| Primary | 当前页最重要的一件事，例如「上传缺失材料」 |
| Secondary | 次要行动，例如「查看条款」 |
| Tertiary / Text | 低强调，例如「返回列表」 |

## 状态（设计稿都要有）

默认 · 悬停 · 按下 · 焦点 · 禁用 · 加载

## 文案

- 用动词 + 宾语
- 英法都要能放下；必要时按钮可变宽，不要缩小字号到不可读

## 无障碍

- 最低高度：先按 40px 草案，官方规范到了再改
- 仅图标按钮必须有无障碍名字
