# 03 · 设计系统

跨项目共用的规则。项目里验证过、还要再被第二个项目用的东西，才写进这里。

## 分层（从上到下越来越具体）

| 层 | 文件夹 | 放什么 |
| --- | --- | --- |
| 基础 | [`foundations/`](foundations/) | 颜色、字体、间距、图标、层级、动效、无障碍 |
| 变量 | [`tokens/`](tokens/) | 给开发对表的名字（token） |
| 组件 | [`components/`](components/) | 按钮、输入框、提示条… |
| 模式 | [`patterns/`](patterns/) | 多个组件的固定用法，如表单报错、状态时间线 |
| 文案 | [`content/`](content/) | 语气、用词、英法注意事项 |
| Figma | [`figma/`](figma/) | 库文件链接、发布节奏 |

变更记在 [`changelog.md`](changelog.md)。不要默默改颜色还不写。

## 什么时候升级进系统

- 同一个组件在两个项目里长得一样，或你明确希望以后都一样
- 已经和工程对过名字
- 无障碍和英法有结论，不是「先这样吧」

项目一次性的视觉实验留在 `02-.../05-explorations/`，不要污染系统。
