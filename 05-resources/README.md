# 05 · 资料库

不属于某一个项目、但以后会反复翻的东西。

| 文件夹 | 放什么 |
| --- | --- |
| [`references/`](references/) | 政策公开页、行业报告摘录、内部公开指南的链接 |
| [`competitive/`](competitive/) | 跨项目的竞品观察（项目专属的仍放在该项目 discovery 里） |
| [`inspiration/`](inspiration/) | 体验参考，注明「学什么、不抄什么」 |
| [`meeting-notes/`](meeting-notes/) | 不绑死项目的例会；项目评审仍放在该项目 `06-reviews/` |

敏感附件只放链接和摘要。
